## 🛠️ 4. แผนงาน (Stages)

### Stage 1 — ชั้นข้อมูลจริง (`assets/dashboard-analytics-service.js`)
- `loadLiveData()` อ่าน `tbl_res_request` (+ `tbl_cmp_case`, `tbl_res_calendar`, ประวัติเลื่อน/ถอนวาระจาก `tbl_res_request_event`) ด้วย singleton `ECMIS.getSupabaseClient()` (กฎเหล็กข้อ 3)
- **ตาราง mapping สถานะ/รหัสมติ → หมวด/รายการ** (แหล่งความจริง = `trr_resolution_data.code`, `resolution72`, `guiltyCriminal72/guiltyDiscipline72`, `trr_status`, `trr_meeting_date`):
  - หมวด ๑ ไต่สวนเบื้องต้น ๗.๑: `ACCEPT_S24P1/P3` → รับไว้ไต่สวน; `NOT_ACCEPTED/DISMISS` → ไม่รับไว้; ส่ง ป.ป.ช./ไต่สวนเพิ่ม ตามรหัสใน `RESOLUTIONS`
  - หมวด ๒ วินิจฉัยชี้มูล ๗.๒: `GUILTY_72` + flags → ชี้มูลอาญา+วินัย/อาญา/วินัย; `NO_MERIT_72` → ข้อกล่าวหาตกไป; `FORWARD_NACC` → ส่ง ป.ป.ช.; `MORE_INVESTIGATE_72` → ไต่สวนเพิ่ม
  - หมวด ๓ เรื่องทั่วไป ๗.๓: `RESOLUTIONS_73` (`APPROVE_73`/`REJECT_73`/`REVIEW_PROSECUTOR_73`/`LEGAL_DIVISION_73`/`SPECIAL_TASK_73`) + `generalType73`
  - หมวด ๔ ถอน/เลื่อนวาระ: จาก event `DEFER_AGENDA` / สถานะ `DEFERRED`
  - หมวด ๕ คดีประพฤติมิชอบ: จาก ฐานการรับเรื่อง ม.๑๘/๔ ที่มีมติ — **รายละเอียดปลีกย่อยของหมวด ๔–๕ ยืนยันจากข้อมูลจริงระหว่าง Stage 1** (แจ้งผู้ใช้ถ้าต้องตัดสินใจ)
- เดือน/ปีงบประมาณ: แปลง `trr_meeting_date` (ค.ศ.) → คีย์ `YYYY-MM` (พ.ศ.) ให้เข้ากับตัวกรองเดิม; ตัวกรองคณะอนุกรรมการใช้ `trr_sub_committee`
- คง `fetchDashboardData()` เดิมเป็นชื่อฟังก์ชัน/โครงสร้างผลลัพธ์เดิม (หน้า/กราฟ/ตาราง/ส่งออกไม่ต้องรู้ว่าแหล่งเปลี่ยน); ถ้าเชื่อม DB ไม่ได้ให้ **แสดงป้าย "ข้อมูลตัวอย่าง (ออฟไลน์)"** ชัดเจน ห้ามแสดงตัวอย่างโดยไม่บอก

### Stage 2 — Real Time (`dashboard.html`)
- `setInterval` 30 วินาที เรียก refresh (หยุดเมื่อแท็บถูกซ่อน `document.visibilityState`, ดึงทันทีเมื่อกลับมา); ป้าย "อัปเดตล่าสุด HH:MM:SS · อัปเดตอัตโนมัติทุก 30 วินาที" + จุดสถานะเชื่อมต่อ; ถ้าดึงพลาดคงข้อมูลเดิมและแสดงคำเตือนไม่ล้างหน้า
- คงปุ่มรีเฟรชกดเองไว้

### Stage 3 — ส่งออก ๓ รูปแบบเป็นไฟล์จริง
- **.xlsx จริง:** SheetJS (cdnjs `xlsx.full.min.js`) — แดชบอร์ด (ตารางสถิติ ๕ หมวด + รายละเอียด) และทะเบียนสำนวน
- **.docx จริง:** ใช้ `ECMIS.exportDocToDocx()` กับตารางรายงาน (แดชบอร์ด) / ตารางทะเบียนสำนวน (ซ่อนใน container แล้วแปลง)
- **.pdf จริง:** `ECMIS.exportDocToPdf()` (html2pdf) แทนหน้าต่างพิมพ์ — ตั้งค่าหน้ากระดาษ A4 แนวนอนสำหรับตารางกว้าง
- ปุ่มส่งออกจัดเป็นกลุ่มเดียวกันทั้ง 2 หน้า (Word / Excel / PDF / CSV คงไว้) ชื่อไฟล์มีวันเวลา

### Stage 4 — ทดสอบ
1. ตัวเลขแดชบอร์ด = ผล query ตรงจาก DB (สคริปต์เทียบทุกหมวด/รายการ)
2. E2E: เปลี่ยนสถานะสำนวนจริงระหว่างเปิดแดชบอร์ด → ตัวเลข/ป้ายเวลาเปลี่ยนภายใน 30 วินาทีโดยไม่กดรีเฟรช
3. ส่งออก: ทั้ง 3 รูปแบบ × 2 หน้า สร้าง Blob ถูก MIME/ขนาด > 0 และเปิดอ่านกลับได้ (xlsx อ่านกลับด้วย SheetJS ตรวจแถว/หัวตาราง)
4. Regression: เส้นทางเลือกเดือน/ปีงบ/คณะ, drill-down modal, dark mode, หน้าอื่นไม่กระทบ; `npm run sync` → `npm test` (5/5) → `npm run test:integration` (60/60)
5. เขียนเคสทดสอบรูปแบบ `****/****` เท่านั้น (ห้าม TEST-xxx) และ soft-delete หลังใช้ (DELETE ด้วย anon key ไม่มีผล)

## ✅ 6. ผลการดำเนินงาน / ข้อค้นพบระหว่างทำ
- **ข้อมูลจริงมีน้อยมาก:** DB เดโมมี 148 สำนวน แต่มีมติบันทึกแล้วเพียง 29 เรื่อง (ไต่สวนเบื้องต้น 23 / ชี้มูล 3 / ทั่วไป 3) ตัวเลขแดชบอร์ดจึงเล็กกว่าข้อมูลตัวอย่างเดิม (412 เรื่อง) มาก — ตามที่ตกลง (T1)
- **หมวด ๔ (ถอน/เลื่อนวาระ) และ ๕ (คดีประพฤติมิชอบ) = 0** เพราะไม่มีข้อมูลรองรับ: ไม่มี event เลื่อน/ถอนวาระเลยใน DB และระบบไม่มีฟิลด์แยกคดีประพฤติมิชอบ (ฐาน ม.๑๘/๔ ถูกใช้กับสำนวน 7.1 ทั่วไป) — ต้องตัดสินใจแยกเรื่องโมเดลข้อมูลก่อนจึงจะนับได้
- **หมวด ๓:** ชนิดเรื่อง 7.3 ในระบบ (`GENERAL_TYPES_73`) ไม่ตรงกับ ๕ รายการในแบบรายงาน กบค. — ที่จับคู่ได้ 3 ชนิด ที่เหลือลงรายการ "อื่น ๆ" (ไม่ทิ้งเงียบ)
- **SLA banner** เดิมเป็นเลขตายตัว (1/2) ตอนนี้คำนวณจากสำนวนที่ยังเปิดอยู่จริง (`trr_sla_days`/`trr_sla_limit`)
- **PDF:** เป็นภาพหน้ากระดาษ (เลือก/ค้นหาข้อความไม่ได้) — ข้อจำกัดของ html2canvas; ต้องตัดบรรทัดไทยเองด้วย `Intl.Segmenter` (html2canvas ตัดบรรทัดคลาด ทำให้ข้อความซ้อนกัน) และบังคับ `letter-spacing:0` (เว็บตั้ง 0.1px ทำให้วรรณยุกต์ไทยเพี้ยน); ตารางกว้าง (ทะเบียนสำนวน) PDF ใช้เฉพาะ 10 คอลัมน์สำคัญ ส่วน Word/Excel ครบ 17 คอลัมน์
- **Word:** สร้าง .docx จริง (OOXML ผ่าน PizZip) ตรวจอ่านกลับด้วย python-docx ได้; ของเดิมในระบบ (`ECMIS.exportDocToDocx`) ยังเป็น HTML ที่ตั้งนามสกุล .docx ไม่ได้แก้ในงานนี้
- Real Time เป็นแบบ polling: ตัวตั้งเวลาหยุดเมื่อแท็บถูกซ่อน (`visibilityState`) และดึงทันทีเมื่อกลับมา; ทดสอบ: เพิ่มสำนวนใน DB ขณะเปิดหน้า ตัวเลขเปลี่ยน 10→11 ภายใน 17 วินาที
- `followup-dashboard.html` (ติดตามผลมติ) ยังใช้ข้อมูลตัวอย่างผสม — นอกขอบเขตแผนนี้
