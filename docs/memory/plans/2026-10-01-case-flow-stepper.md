# แถบขั้นตอน (stepper) ตามเส้นทางจริงของเคส

**สถานะ:** Completed (2026-10-01)

## ปัญหา
แถบขั้นตอนบนหน้าเอกสารเป็นชุดตายตัว (7.1 = 7 ขั้น, 7.2/7.3 = 5 ขั้น) และบางหน้าใช้ชุดผิดสาย
(chairman-agenda/chairman/review ใช้ชุด 7.1 กับทุกเคส, order/order-m24 ตรึงไว้ที่ขั้นมติ) ไม่สะท้อนผู้ดำเนินการและทางที่เคสเดินจริง

## ตัดสินใจ (AskUserQuestion 2026-10-01)
1. ขั้นตามเส้นทางจริง ทีละผู้ดำเนินการ — สร้างจากสาย + ทาง (ด่วน/ไม่ด่วน, ยุ่งยาก/ไม่ยุ่งยาก) จำนวนขั้นไม่ตายตัว ฟังก์ชันกลางตัวเดียว
2. ทางแยกที่ยังไม่ตัดสิน (7.2 ก่อนประธานฯ คัดกรอง) แสดงขั้นกลาง "ดำเนินการตามผลคัดกรอง" แล้วเปลี่ยนเป็นขั้นจริงหลังตัดสิน
3. ลำดับชั้นก่อนถึงเลขาฯ รวมเป็นขั้นเดียว "เสนอตามลำดับชั้น"
4. ใต้ชื่อขั้น: บทบาทผู้ดำเนินการ + วันที่ทำเสร็จ (จาก tbl_res_request_event)
5. วนกลับ (ตีกลับ/ขอข้อมูลเพิ่ม/ไต่สวนเพิ่ม/เลื่อนวาระ): ขั้นที่เคสอยู่เป็นสีส้ม + ป้ายเหตุ ไม่เพิ่มขั้นซ้ำ
